## 1. حذف جداول المورّدين والمخزون والمشتريات

### ما تمّ
- **حُذف ملفان يتيمان:** `lib/models/supplier_model.dart`، `lib/models/purchase_model.dart`
- **`lib/sqldb.dart`:** أُزيلت تعريفات الجداول الثلاثة من `_onCreate` ومن `_onUpgrade`، وأُضيفت حلقة حذف في نهاية `runPendingMigrations()`:

```dart
for (final table in ['inventory', 'suppliers', 'purchases']) {
  try {
    await mydb.execute('DROP TABLE IF EXISTS "$table"');
  } catch (e) {
    debugPrint('تعذّر إزالة الجدول $table: $e');
  }
}
```

الحذف **آمن ومتكرّر التنفيذ** (idempotent): يعمل على أي قاعدة قائمة، ولا يفشل لو كان الجدول محذوفًا أصلًا.

- **`SessionManager.canManageInventory()`** → أُزيلت (صار كودًا ميتًا بعد الحذف).

### التحقّق
البحث عن أي إشارة حقيقية للجداول الثلاثة في الكود كله أظهر **صفر نتائج**. المتبقي فقط أيقونات واجهة عامة (`Icons.inventory_2_outlined` تُستخدم كأيقونة «لا بيانات») وهي لا علاقة لها بالمخزون.

**مهم:** لم تكن في هذه الجداول أي بيانات — لم يُقرأ منها ولم يُكتب فيها صف واحد في التطبيق كله. الحذف لا يُفقد شيئًا.

### تفصيل حماية الحذف التلقائي (بند ن)

كان `deleteOldInvoices()` يعمل تلقائيًا وصامتًا. الآن:

1. **معطَّل افتراضيًا** — لا حذف إلا بتفعيل صريح من الإعدادات.
2. **لا يحذف فاتورة عليها دَين متبقٍّ** — حماية للأرصدة والديون.
3. **لا يحذف فاتورة اشتراك** — سجلّ الاستهلاك يجب أن يبقى.
4. **حد أدنى 400 يوم** — أطول من سنة ميلادية، فلا يمسّ ما قد يدخل في مقارنة «السنة الماضية».
5. **إشعار مرئي** بالعدد والمبلغ + تسجيل في سجل التدقيق.

وأُضيف قسم **«الاحتفاظ بالبيانات»** في شاشة الإعدادات: مفتاح تشغيل/إيقاف صريح + حقل مدة الاحتفاظ + تحذير.

## 3. واتساب بضغطة من قائمة الفواتير

### الخلل الجذري الذي كان يمنع التسليم
الزر القديم كان يبني `wa.me/$cleanPhone` بـ**الأرقام الخام بلا رمز دولة**. رقم مثل `0537498756` لا يعرفه واتساب كرقم دولي → **الرسالة لا تُسلَّم أصلًا**.

### ما تمّ
- `_WhatsAppShareBtn` في قائمة الفواتير تُفوّض الآن لخدمة المشاركة المركزية `InvoiceShareService.sendInvoiceToCustomer`.
- **`normalizePhone`**: `05xxxxxxxx` → `9665xxxxxxxx`، مع معالجة `+`، وبادئة `00`، والمسافات، والشرطات، والأرقام التسعية.
- **لو الزبون بلا رقم:** يُفتح حوار لإدخاله، ثم يُحفظ في سجل الزبون ويُربط بالفاتورة — فلا يتكرّر الطلب في المرة القادمة.

### التحقّق العملي (12/12)
```

'+966537498756'     → 966537498756   ✅
'00966537498756'    → 966537498756   ✅
'537498756'         → 966537498756   ✅  9 أرقام
'0537 498 756'      → 966537498756   ✅  بمسافات
'053-749-8756'      → 966537498756   ✅  بشرطات
```
